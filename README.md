# Exposure: Mail and News

Аддон для мода [Exposure](https://modrinth.com/mod/exposure) — **Minecraft 1.21.1 (NeoForge)**.

Добавляет бумажные записки, конверты с почтовыми марками и сургучной печатью, 12-страничные газеты с фотографиями из Exposure, а также бумажные поделки (бумажную шапочку, самолётик и бумажный кораблик, который ставится на воду как кувшинка). Все предметы мода находятся напрямую во вкладке **Exposure** в творческом инвентаре.

## Установка / Installation
Поместите собранный `.jar`-файл в папку `mods/` вместе с модом **Exposure 1.9.19+** (NeoForge 1.21.1). Требуется и на клиенте, и на сервере.

## Сборка / Build
```bash
./gradlew build        # -> build/libs/
./gradlew runClient    # запуск тестового клиента
```
В репозитории также настроен GitHub Actions (`.github/workflows/build.yml`) для автоматической сборки `.jar` при каждом коммите в `main`/`master`.

## Предметы и возможности / Features
| Предмет | Крафт | Описание |
| --- | --- | --- |
| **Записка (Note)** | 1 бумага в сетке крафта (и обратно: 1 записка -> 1 бумага) | Интерфейс отдельного бумажного листа; можно подписать и запечатать как книгу или разместить на кафедре (отображается собственной 3D-моделью листа) |
| **Конверт (Envelope)** | Бумага + пчелиные соты | Вмещает до 5 предметов (записки, бумагу, карты, фотографии, газеты), поля «От» / «Кому», наклеивание почтовой марки и запечатывание кнопкой. Запечатанный конверт открывается мгновенно по ПКМ |
| **Почтовая марка (Postage Stamp)** | Фотография Exposure + узор флага (узор не тратится) | 9 дизайнов марок; наклеивается ПКМ по конверту в инвентаре |
| **Пустая газета / Газета (Newspaper)** | 3 бумаги | 12-страничный редактор: название, заголовки, подзаголовки, текст, разделители и до 3 фотографий на страницу (при наличии разделителя фото размещаются под ним). На кафедре отображается собственной 3D-моделью газеты |
| **Бумажная шапочка (Paper Hat)** | 5 газет (форма шлема) | Косметический окрашиваемый головной убор с полигональной 3D-моделью, размокает под дождём |
| **Бумажный самолётик (Paper Plane)** | 5 записок в виде перевёрнутой «Т» (и 1 самолётик -> 1 записка) | Сохраняет текст и автора записки при складывании и разворачивании; запускается броском |
| **Бумажный кораблик (Paper Boat)** | 5 записок, листов бумаги или газет в форме лодки (и 1 кораблик -> 1 записка) | Размещается на воде как кувшинка с 3D-моделью оригами-кораблика и сохраняет текст записки |
